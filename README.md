# PySprout

A Python-learning game for iPhone (and any browser). Learn with a companion through story-mode lessons, then test yourself in survival-mode coding quests that run real Python 3 in the browser.

**Play:** https://varaha18.github.io/pysprout/
On iPhone, open the link in Safari → Share → **Add to Home Screen**.

## Features

- Story mode: short lessons with a companion character
- Survival mode: coding quests checked by real Python 3 ([Skulpt](https://skulpt.org/))
- Adaptive learning: onboarding level check and 8 learning tracks
- Play as a guest (progress saved on the device) or sign in with email/Google to sync progress across devices (Firebase)

## Files

| File | Contents |
|---|---|
| `index.html` | The whole app |
| `config.js` | Firebase web config (safe to publish; Firestore rules protect the data) |
| `manifest.json`, `logo.png`, `icon*.png` | Home Screen app manifest and icons |
| `SETUP.md` | How to host it on GitHub Pages and turn on sign-in |
